# Macro Mode

Macro Mode is built for power users who want repeatable automations without surrendering privacy.

## Enter Macro Mode

Toggle **Macro Studio** from the FormMirror tray. You’ll see the current screenshot on the left and your automation workspace on the right.

## Region selector

Draw labeled regions over the screenshot to capture the data you want re-used. Each region records coordinates, applied filters, and match history.

- Resize handles snap to edges.
- Hold `Shift` for perfect squares.
- Keyboard nudges adjust position 1px at a time.

## Extraction tweaks

Per-region controls let you:

- Apply color filters to neutralize backgrounds.
- Adjust exposure/contrast for tricky scans.
- Flag regions as multiline or numeric for smarter parsing.

## Link regions to fields

Today you can map regions to selectors via the review table. Field-linking UI is in progress, so you’ll drag connections directly onto the live form soon.

## Run macros

When you execute a macro, FormMirror crops the relevant regions, re-runs OCR locally, and streams the recognized values back into the fill pipeline. Version history keeps track of edits so you can roll back instantly.
