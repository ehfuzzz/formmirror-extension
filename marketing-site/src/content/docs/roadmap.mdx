# Roadmap

Here’s what’s on deck for FormMirror. Timelines are intentionally flexible because privacy and quality come first.

## Near term

- **Field-linking UI** that lets you drag screenshot regions directly onto live form fields.
- **Custom OCR language packs** for multilingual workflows.
- **Synonym packs** so you can import domain-specific vocabularies.

## Mid term

- **Macro diffing** to compare changes between versions.
- **Debug overlays** that visualize similarity scores on the page.
- **Workspace sharing** with encrypted export/import files.

## Long term

- **Localization** for the extension UI and docs.
- **Extensibility hooks** for enterprise automation platforms.
- **Opt-in analytics** that stay on-device but surface richer macro insights.

Want to influence the roadmap? Open the GitHub repository and file an issue with your workflows and we’ll explore partnerships.
